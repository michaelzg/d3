About this experiment +

These fictional population totals are anchored to real city locations. Seeded clusters are scattered around each center and clipped to land. Panel area is proportional to simulated population; the map projection refits whenever a panel changes size. On smaller screens, equal-sized panels keep the maps readable. Every map uses its own scale, so dot concentration should not be compared as measured population density. Resimulate generates a new set of populations and clusters.
